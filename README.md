AegisFlowAutonomous CI/CD Incident Triage, Root-Cause Analysis, and Sandboxed Code-Repair AgentAegisFlow is a production-oriented autonomous engineering platform that catches broken GitHub Actions builds, filters out noisy infrastructure flakes in milliseconds, diagnoses code regressions, verifies fixes inside isolated containers, and opens ready-to-review Pull Requests.Rather than streaming every raw build log to an expensive Large Language Model (LLM), AegisFlow combines classical machine learning (XGBoost and scikit-learn) with local LLM inference (vLLM), standardized tool calling via the Model Context Protocol (MCP), hybrid vector + episodic memory (pgvector), and secure container sandboxing (Docker SDK for Python).Why AegisFlow ExistsModern engineering teams lose hours every week investigating failed CI/CD pipelines. Existing AI coding assistants struggle with automated incident remediation for three reasons:Unfiltered Log Noise Drives Up Token Costs: Passing thousands of lines of transient network timeouts or flaky container logs directly to frontier LLMs wastes compute and increases latency.Brittle Prompt-Based Tooling: Hardcoded regex tool parsers break across repositories and lack standardized schema validation.Unsafe Code Execution: Allowing an autonomous agent to run arbitrary shell commands or test suites directly on a host runner introduces severe security risks.AegisFlow solves each of these bottlenecks through a multi-stage, observable architecture.System ArchitectureEnd-to-End Remediation WorkflowWebhook Ingestion (FastAPI): Receives real-time workflow_run failure events and log archives from GitHub Actions.Millisecond Triage Gate (XGBoost + PyTorch): Extracts structural log features (exit codes, stack-trace depth, error token entropy, recent commit churn) to classify the failure into:TRANSIENT_FLAKE (triggers an automated workflow re-run without invoking the LLM)DEPENDENCY_CONFLICT (routes to lockfile resolution workflow)CODE_REGRESSION (escalates to the deep MCP remediation agent)Hybrid Context & Episodic Memory Retrieval (pgvector): Queries PostgreSQL for AST-chunked repository files (BM25 + dense embeddings) alongside historical incident trajectories to surface how similar bugs were resolved previously.Agentic Investigation via MCP: Orchestrates a state-machine agent loop served by vLLM that invokes strictly typed tools exposed through the MCP Python SDK (git_blame, ast_symbol_search, read_file_span, apply_unified_diff).Isolated Verification Sandbox (Docker SDK for Python): Spins up an ephemeral, network-disabled container with strict CPU/memory quotas, applies the candidate patch, and runs the repository's test suite.Observability & Human-in-the-Loop Approval (OpenTelemetry): Streams full execution traces, token budgets, and sandbox diffs to a React + TypeScript control plane before opening a verified draft Pull Request.Tech Stack OverviewLayerTechnologies UsedEngineering ResponsibilityClassical ML & RoutingPython, XGBoost, PyTorch, Open http://localhost:3000 to watch the live triage decision, MCP tool invocations, container test execution, and generated patch diff.Security & Sandbox Isolation ModelExecuting LLM-generated code requires strict defense-in-depth boundaries. Every verification run inside packages/sandbox-runner enforces the following constraints via the Docker SDK for Python:Zero Outbound Network Access: Containers launch with network_mode="none" after dependency installation so untrusted patches cannot exfiltrate secrets or make external requests.Strict Resource Quotas: Enforces mem_limit="512m", nano_cpus=1_000_000_000 (1 vCPU), and pids_limit=64 to prevent fork bombs or memory exhaustion.Read-Only Root Filesystem: Mounts the root filesystem as read-only (read_only=True) with an ephemeral in-memory tmpfs mount solely for /tmp and test artifacts.Unprivileged Execution: Drops all Linux capabilities (cap_drop=["ALL"]) and executes tests under a non-root user UID.Evaluation & Reproducible BenchmarksAegisFlow includes automated evaluation harnesses under benchmarks/ so every architectural change can be measured quantitatively.
